ALUR & LOGIKA SISTEM

Penjelasan teknis mengenai metode Fuzzy Mamdani dan Forward Chaining yang digunakan.

1. Fuzzy Mamdani (Estimasi Harga)

Metode ini menangani ketidakpastian dalam menentukan harga berdasarkan variabel yang bersifat subjektif seperti "Kerumitan".

Tahapan:
  • Fuzzification: Mengubah input numerik menjadi nilai linguistik (Misal: Kerumitan 7.5 -> "Tinggi").
  • Inference: Mengevaluasi 9 aturan fuzzy (Rules) untuk menentukan kategori harga.
  • Composition: Menggabungkan hasil dari semua aturan yang aktif.
  • Defuzzification: Menggunakan metode Centroid untuk mendapatkan nilai rupiah tunggal.
2. Forward Chaining (Diagnosa)

Metode penalaran yang dimulai dari sekumpulan fakta (gejala) menuju kesimpulan (masalah).

Tahapan:
  • Data Driven: Pengguna memberikan fakta berupa gejala yang ditemukan.
  • Pattern Matching: Sistem mencocokkan pola gejala tersebut dengan basis aturan (IF-THEN).
  • Certainty Factor: Menghitung tingkat keyakinan (Confidence Level) berdasarkan kecocokan gejala.
Arsitektur Teknologi
Backend
Python Flask - Menangani logika inferensi fuzzy dan mesin sistem pakar secara efisien.
Frontend
Vanilla JS & CSS - Antarmuka responsif tanpa framework berat, menjaga kecepatan sistem.
Deployment
Vercel Serverless - Memungkinkan sistem diakses secara online dengan skalabilitas tinggi.
Data Format
JSON API - Komunikasi data antara frontend dan backend dilakukan secara asinkron.
